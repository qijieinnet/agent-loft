# 个人 bot 的后端接入

## 怎样给已有专家一个持久入口

### Takeaway
专家配置可以复用。应给用户自己的 bot 持久保存到一条主会话的关联，使用者身份来自登录会话。

### Cited Findings
- 专家定义区分所有者、可使用者、使用者个人的技能与 MCP。成员使用共享专家时默认只带自己能用的资源。[experts.ts](../../src/core/experts.ts#L215)
- Web 新会话会校验专家访问、驱动启用状态和工作目录，最后调用 Hub 创建显式记录 owner 的会话。Web 会话创建后，换专家需要另开会话。[Web API](../../src/channels/web/api.ts#L975) · [Hub](../../src/core/hub.ts#L1961)
- 删除会话会隐藏记录并清除历史索引、资料和预约消息。开会话时个人记忆根据对话使用者读取；停用账号没有个人记忆。[Web API](../../src/channels/web/api.ts#L131) · [personal.ts](../../src/core/personal.ts#L24)

### Inferences
- 从专家创建或打开 bot 时复用新会话的鉴权逻辑，服务端同步选取或创建入口。换专家或删除会话应采取可预测的行为，避免在同一对话中途切换身份。共享专家的每位使用者都应有独立会话。
- 验收双击创建、刷新或服务重启、删会话后再打开、专家取消共享或引擎停用等情形。

### Gaps
- 当前运行环境中各用户实际启用的驱动、专家和绑定需要在对应部署实例确认。

## 怎样让定时工作归到 bot 名下

### Takeaway
任务服务已有归属、调度、推送和运行记录。可以直接按主会话查询现有任务；专用会话任务要准确追溯创建来源，需要记录来源。

### Cited Findings
- 任务保存 owner、target、notify、推送目的地、执行专家及最近二十次运行；调度器执行前复核权限、目标归属、忙碌状态和挂起审批，重启时标记执行中的运行为中断。[任务模型](../../src/core/tasks.ts#L45) · [调度执行](../../src/core/task-runner.ts#L52) · [重启恢复](../../src/core/task-runner.ts#L230)
- 自然语言创建任务使用当前会话的专家和目录，默认回复本会话，也允许专用会话；创建需经现有确认卡。后者的 target 记录专用会话键，未保留发起时的聊天键。[任务工具](../../src/core/tasks-bridge.ts#L138)
- 当前智能通知在模型生成结果后判断静默。推送订阅、飞书绑定私聊和微信已分别消费现有结果事件。[Hub](../../src/core/hub.ts#L877) · [Web](../../src/channels/web/server.ts#L472) · [飞书](../../src/channels/feishu/index.ts#L46) · [微信](../../src/channels/weixin/index.ts#L35)

### Inferences
- bot 首页可根据显式所属关系展示任务、上次结果和待审批事项。老任务中同一专家可能在多个独立项目使用，按专家 ID 批量认领会混入其他工作。
- 后续若实现低成本主动监听，在调度前加入限定数据源的预检，将游标和去重标记落盘。读取失败应保留旧游标。

### Gaps
- 飞书任务回执直接发到绑定 openId；实际抵达手机不能从服务端任务记录证明。[飞书投递](../../src/channels/feishu/index.ts#L47)

## 如何在飞书上延续同一 bot

### Takeaway
已有续接会话、事件镜像和交互卡处理链路。个人 bot 如果进入此链路，应在续接和每次投递时认定当期绑定的本人私聊。

### Cited Findings
- 飞书收到私聊时根据发送人的绑定重设归属，再路由到挂接的 Web 会话。挂接后历史、回复和待审批卡都可能显示在该飞书聊天。[入站](../../src/channels/feishu/bot.ts#L672) · [挂接](../../src/channels/feishu/bot.ts#L270)
- 普通 Web 会话现有可见性在无主飞书聊天时采用 adminVisible；该函数会匹配管理员拥有的会话。现有 Web 代选飞书聊天的 API 限制为管理员。[飞书可见性](../../src/channels/feishu/bot.ts#L166) · [归属](../../src/core/users.ts#L228) · [Web 挂接入口](../../src/channels/web/api.ts#L1215)

### Inferences
- 对个人 bot 关联的会话采用更具体的主人检查，覆盖列表、卡片点击、挂接、已挂接会话查询与 watchers。解绑后停用旧映射，验证对已取消绑定的聊天不再展示新的内容。

### Gaps
- 真机飞书收信、系统推送回执和设备通知权限应作为发布前人工或测试账号验收项。
